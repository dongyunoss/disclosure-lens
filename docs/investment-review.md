# 투자 검토 기준 v1

목적은 재무제표의 변화로부터 검토할 질문을 만드는 것입니다. 결과는 예측, 신용등급, 투자 점수 또는 사실로 확정한 원인이 아닙니다. 아래 임계값은 초기 제품의 고정 탐색 기준이며 통계적으로 보정하거나 업종별로 검증한 값이 아닙니다. 모든 카드에서 계산 방식과 한계를 열어 볼 수 있습니다.

| 검토 질문 | 표시 기준 | 후속 확인 |
|---|---|---|
| 수익성 | 영업이익 0 이하 또는 영업이익률 2%p 이상 하락 → 확인 우선. 그 외 2%p 이상 상승 → 주요 변화 | 제품·사업부 구성, 가격·물량, 원가, 일회성 비용 |
| 매출채권 | 기말 잔액 증가율이 매출 증가율보다 5%p 이상 큼 → 확인 우선 | 연령 분석, 대손, 회수 조건, 환율·인수 영향 |
| 재고 | 기말 잔액 증가율이 매출 증가율보다 5%p 이상 큼 → 확인 우선 | 구성, 평가손실, 회전, 수요 |
| 이익의 현금 전환 | 영업현금 음수 또는 영업현금 / 순이익 < 1배 → 확인 우선 | 비현금 손익, 감가상각, 운전자본 |
| 운전자본 | 현금효과 악화액 / 전기 영업현금 ≥ 10% → 확인 우선 | 현금흐름 주석의 자산·부채별 조정 |
| 유동성 | 유동자산 / 유동부채 < 1배 → 확인 우선 | 현금 사용 제한, 금융상품·차입 만기 |
| 단기차입 | 증가율 ≥ 20% → 확인 우선 | 사용 목적, 통화, 만기, 금리, 보유 현금 |
| 자산 취득 | 유형·무형 취득 지출 / 영업현금 > 100% → 확인 우선 | 유지·성장 투자 구분, 투자 회수 |
| 무형자산 | 장부금액 증가율 ≥ 20%, 총자산 비중 ≥ 3% → 주요 변화 | 영업권, 개발비, 손상검사 |
| 주주환원 | 양의 배당·자사주 지출이 FCF 초과 → 확인 우선. 그 외 자사주 취득 증가율 ≥ 50% → 주요 변화 | 환원 정책, 소각·처분, 투자·차입 계획 |

금액은 문자열로 전송하고 Python 정수/Decimal과 브라우저 BigInt로 처리합니다. FCF = 영업현금 − 유형자산 취득 지출 − 무형자산 취득 지출. 원문의 음수 지출은 양의 규모로 정규화하며 원본 표는 바꾸지 않습니다. 비율의 분모가 0 이하이거나 필수 항목을 확보하지 못하면 판단 보류합니다. 음의 영업현금 자체는 비율 없이도 확인 대상으로 남깁니다. 판단은 반올림 전 값으로 수행합니다.

삼성전자 2025 보고서의 당기와 전기 비교열을 사용합니다. 재무상태표는 각 연도 말 잔액, 손익·현금흐름은 연간 누적입니다. 기말 매출채권·재고와 연간 매출을 비교한 증가율은 DSO나 재고회전일수가 아닙니다. 공식 IR PDF의 최종 정정 여부는 미확인입니다.

현재 주석의 대손·재고평가·손상, 만기·약정·현금 사용 제한, 우발채무·소송·특수관계자, 사업부·지역별 원인과 일회성 손익, 동종업계·주가·밸류에이션은 판단 범위 밖입니다. `설정 기준 미해당`은 해당 고정 기준을 넘지 않았다는 뜻이며 안전 판정이 아닙니다.

`pipeline.investment_review.screen`은 회사별 문구와 분리된 계산 엔진입니다. `pipeline.review_sources`가 원문 행·셀을 연결하고, 공개 검증에서는 모든 결과를 재계산합니다. 새 기업·기간에 적용하려면 동일 기준의 원문 추출과 셀 매핑을 먼저 검증해야 합니다. 원인 설명은 회사가 명시한 근거가 확보되기 전에는 검토 질문으로만 제공합니다.

재무제표의 관계와 함께 읽을 항목은 [SEC 재무제표 입문 안내](https://www.sec.gov/about/reports-publications/investorpubsbegfinstmtguide)를 참고했습니다. 위 임계값은 SEC의 권장 기준이 아닙니다.
